## Demo and interview requests

`access.html` contains two native HTML forms that POST to FormSubmit for delivery
to the contact address already published in the portfolio, `Dhunt22@ASU.edu`.
No backend, API keys, JavaScript, or build step is required for GitHub Pages.
The unused Formspree/Cal.com script had no configured endpoint and was removed.

Before relying on delivery, the mailbox owner must submit a test request from the
deployed page and confirm FormSubmit's activation email. Follow any confirmation
instructions for both forms, then send a demo request and an interview request
and verify that both arrive with distinct subjects and the visitor's reply-to
address. Check spam if the activation message does not arrive.

CAPTCHA and FormSubmit's hosted confirmation page use the service defaults. Each
form also includes a honeypot. Visitors are told that FormSubmit processes their
submission and are offered a direct email alternative. See https://formsubmit.co/
for service details. Delivery depends on activation and service availability.
